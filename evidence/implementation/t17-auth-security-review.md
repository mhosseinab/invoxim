## Primary documentation and limitations

[Microsoft UserInfo](https://learn.microsoft.com/en-us/entra/identity-platform/userinfo) supports delegated OIDC scopes for personal/work identities, describes Graph access tokens as opaque and states UserInfo claims correspond to ID-token values.
