# Exact domain kernel

Pure portable arithmetic; no infrastructure, persistence, mailbox access or inference. `@invoxim/core` exports source TypeScript for consumer bundlers. Build checks types without emitting an independent bundle.

`parseMoney` validates currency precision and the per-entry magnitude bound of 9,000,000,000,000 minor units. Unknown amounts remain null. `formatMinor` produces exact decimal text without locale grouping. `ledgerTotals` takes already accepted payment/refund magnitudes and eligibility, validates dates/currency/bounds, and returns integer strings. A period is start-inclusive/end-exclusive. Mixed currencies require explicit per-entry valuation elsewhere; no rate-one fallback. These pure reductions do not deduplicate event identities: future persistence/reconciliation must enforce idempotency before supplying accepted entries.

`financialEntries` classifies verified facts; callers must establish evidence grounding or manual confirmation before setting `verified`. A client flag or model assertion cannot establish verification. It excludes statements, credit notes, unpaid invoices, pending refunds and store-credit payments from cash totals. It uses payment/refund magnitudes, never substitutes document totals. Unknown payment and missing financial fields stay in review. A credit note with explicit completed-refund evidence stays in review for later reconciliation; its label alone never creates a refund. This function neither persists entries nor establishes purchase matching or invoice reconciliation.

`convertMinor` uses positive exact decimal rates and half-away-from-zero rounding per signed entry; sum valuations only after entry conversion. `historicalRateDate` selects only a preceding rate within the specified maximum age. Calendar dates retain their printed basis; timestamp-derived dates use a validated IANA timezone and reject invalid clocks. Monthly anchors clamp without losing their original day. Annual estimates and price differences never create ledger events.

Supported currencies are the reviewed SIX subset EUR/USD/GBP/CHF (2 digits), JPY (0), KWD (3), published 2026-09-17. Other ISO currencies fail closed until independently reviewed. Reference and hash are recorded in `evidence/implementation/t03-currency-reference.txt`. No live rates or provider connections are supplied.
